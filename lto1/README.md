## 四、🔴 为什么停批（技术原因，务必记录）

| 时点 | 现象 |
|---|---|
| 23:10 | `tianping` 账号发现内存 **available 仅 146 MB**（LTO-1 占 1.36 GB / 1.97 GB）|
| 23:15 | `pip install numpy` **wheel 16.7 MB 下载卡 5 min+失败** ⇒ `smell_rd_01` 无法建venv |
| 23:30 | 绕过：复用 `/home/ubuntu/world/the-world/.venv`（只读可执行，已有 numpy 2.5.3）|
| 23:40 | fish 批准停 LTO-1 ⇒ **内存 available 146 MB → 1 189 MB（+6 倍）** |

**🔴 教训**：
1. **2 GiB 机器上不能同时跑"长跑批"+"装包"** ⇒ 长跑批期间**必须预先装好依赖**；
2. **多账号机器上的权限边界要早查**：`tianping` 在 sudo 组但需密码 ⇒ 杀不掉 `ubuntu` 进程；
   最终靠 **`ubuntu` 账号有免密 sudo** 才停掉（`tianping` 的公钥也在 `ubuntu` 的 authorized_keys 里）。
