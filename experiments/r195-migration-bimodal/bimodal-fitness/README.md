## 一句话结论

给定现行捕食/取食公式，适应度地形 `W(g)` 在 `g=1` 处是**吸收边界**，
在 `g∈(0,1)` 上**不存在内部极小（谷）**。

分岔理论：**disruptive selection（分裂选择）产生双峰的必要条件是适应度地形存在内部极小**
（中间表型劣势）。既然不存在，则**双峰在该公式下数学上不可能** ——
这与"跑不出来"是两回事：不是算力/时长不够，是**解空间里根本没有那个解**。

## 被证伪的公式（现行引擎）

```
hunger          = ...                                        # sphere_engine.py L2908
attack_prob(g)  = g · attack_prob_coef · hunger              # L2913
attack gate     = g > attack_gene_gate                       # L2934 / L2940
attack cost     = attack_cost                                # L3013 / L3027
success(g)      = clip(E/(E+Ep) · (0.5 + g·success_gene_gain), floor, ceil)   # L2973 / L3033
transfer        = success · E_prey · transfer_ratio          # L3049 / L3075
```

适应度：

```
W(g) = (1-g)^k · F
     + 1[g > gate] · [ p(g)·σ(g)·E_prey·r − p(g)·c ]
```

其中 `p(g) = g·coef·hunger`，`σ(g) = clip(E/(E+Ep)·(0.5+g·gain), floor, ceil)`。

**关键结构性事实**：`p(g)`、`σ(g)` 均对 `g` **单调不减**，
`1[g>gate]` 是阶跃（只关不开），`(1-g)^k·F` 对 `g` 单调不增。
⇒ 在 `g>gate` 段，`W(g)` 的两个分量"此消彼长但都单调"，
导数**最多变号一次** ⇒ **不可能出现"极小-极大-极小"的谷-峰结构**。

## 验证：18 组参数全扫（解析 + 高精度网格）

脚本用 200001 点网格 + 解析导数变号法找驻点，
并用阈值 `tol=1e-6` 过滤数值噪声，判定 `g∈(0.05,0.95)` 内是否存在内部极小。

```
python3.12 analyze_bimodal_fitness.py
```

| 组 | 扫描维度 | 参数点 | 是否出现内部谷 |
|---|---|---|---|
| A | 基线，只调 `k` | `k = 0, 1, 2, 3, 5` | **无**（5/5） |
| B | 能量不对称 `e_self/e_prey` | `150/150, 300/150, 900/150` | **无**（3/3） |
| C | 攻击成本倍率 | `cost×1, 5, 20, 50, 100, 200` | **无**（6/6） |
| D | 组合（不对称 + 高成本） | `(300,20), (300,50), (900,50), (900,100)` | **无**（4/4） |
| | **合计** | **18 组** | **18/18 无内部谷** |

原始输出见 `bimodal_falsification_proof.txt`（126 行）。

### 典型输出（节选）

```
k=3.0    基线
  W(g):  g=0 → 1.0000 | g=.3 → 0.9250 | g=.5 → 1.2450 | g=.7 → 1.8050 | g=1 → 2.9900
  ⇒ ❌ 无内部谷 ⇒ 单向收敛（边界最优）
```

注意 `g=.3` 处 `W=0.9250 < W(0)=1.0000` —— 这是 `(1-g)^k` 的下降段，
**不是谷**：它之后单调上升到 `g=1` 的 2.99，`g=1` 才是全局最优（吸收边界）。
"中间有一个低点"≠"内部极小"，判据要求的是**两侧都上升的局部极小**。

## 为什么"提高攻击成本"救不了

最常见直觉：把捕食成本 `c` 调大，让"半吊子捕食者"亏本 ⇒ 造中间劣势。

扫描 `cost×1 → ×200` 全部无谷。原因：
`cost` 进入的是 `−p(g)·c` 项，而 `p(g)=g·coef·hunger` **仍单调增**。
抬高 `c` 只是把 `g>gate` 整段整体压低，**不改变单调性** ⇒ 极值点仍只可能出现一次，
且必然落在边界（`g=gate` 或 `g=1`）。**单调性不破，谷就不来。**

同理，`e_self/e_prey` 不对称只缩放 `σ(g)` 的斜率，也不破单调性。

---

## 满足"内部谷"需要什么（数学必要条件）

要造内部极小，必须让 `W(g)` 在 `g>gate` 段出现**非单调**。可行路径（详见建议文档）：

1. **非单调的 `σ(g)`**：成功率中间低两头高（如"技不配位"的惩罚项）
2. **负频率依赖**：中间表型被两头同时压制（真实生态学常见，如资源分割 + 竞争）
3. **空间庇护所**：中间表型在空间上被挤到低产区块

三者都不是"调参"能实现的 —— 需要**改公式结构**。

## 诚实边界

1. **本证伪针对解析地形，不是动力学模拟**。它证明的是"该公式族的适应度地形无内部谷"，
   因此双峰**不可能是稳定进化结果**；但它**不排除**瞬时/非平衡的多峰分布
   （例如空间异质 + 强漂变）。若观测到瞬态多峰，应属此类，需另行区分。
2. **参数覆盖有限**：18 组覆盖了 `k`、能量比、成本倍率，但**未扫** `gain`、
   `floor/ceil`、`transfer_ratio`、`gate`。不过结论依赖的是**单调性（结构性）**而非具体数值，
   故预期不随这些参数改变；如需彻底封口，可加扫——已在建议文档列为后续项。
3. **未跑动力学长程验证**（如用 g16 分布直方图看是否单峰）。
   解析结论强于数值结论，但若有人质疑"解析没考虑种群结构"，
   补一个 200k tick 的 g16 分布直方图实验是最直接的回应。
