# 云端实验速度测试报告

**测试日期**：2026-09-13
**测试环境**：云端容器（2核CPU / 3.9GB内存 / Python 3.12 / numpy 2.5.3）
**测试脚本**：`experiments/a4_verify_capacity.py`（Python路径，use_sim_core=False）
**测试配置**：--mode on --seed 99 --codebook 0（独立测试，不影响R19正式实验）

## 一、测试方法

分两个阶段测量：
1. **初始增长阶段**：从 tick=0（N0=200）跑到 tick=5000，测量总时间
2. **大种群稳定阶段**：从 tick=5000（N≈5000）续跑到 tick=7000，测量总时间

## 二、测试结果

### 2.1 初始增长阶段（tick 0→5000）

| 指标 | 值 |
|------|-----|
| 总 tick | 5000 |
| 总时间 | 181 秒（3分1秒） |
| **平均速率** | **27.6 tick/s** |
| N 变化 | 200 → 4999（增长至 max_count） |

种群增长轨迹（每500 tick采样）：
- tick=500: N=67
- tick=1000: N=66
- tick=2000: N=158
- tick=3000: N=549
- tick=4000: N=2122
- tick=5000: N=4999

### 2.2 大种群稳定阶段（tick 5000→7000）

| 指标 | 值 |
|------|-----|
| 总 tick | 2000 |
| 总时间 | 160 秒（2分40秒） |
| **平均速率** | **12.5 tick/s** |
| N | 稳定在 5000（max_count） |

## 三、单实验时间推算

以 60000 tick/实验、大种群稳定在 N=5000 为例：

| 阶段 | tick | 速率 | 时间 |
|------|------|------|------|
| 初始增长 | 0→5000 | 27.6 t/s | ~3 分钟 |
| 大种群稳定 | 5000→60000 | 12.5 t/s | ~73 分钟 |
| **总计** | **60000** | — | **~76 分钟/实验** |

**小种群实验**（如 N≈300-500 的稳定小种群）：
- 估算速率：约 40-50 tick/s（N 小，计算量小）
- 总时间：约 20-25 分钟/实验

## 四、10实验总时间估算（R19验收批）

| 实验类型 | 数量 | 单实验时间 | 小计 |
|----------|------|-----------|------|
| 大种群（N≈5000） | ~7个 | 76分钟 | 532分钟 |
| 小种群（N≈300-500） | ~3个 | 25分钟 | 75分钟 |
| **总计（串行）** | **10个** | — | **~607分钟（~10小时）** |

**分段续跑实际效率**：
- 每轮 TIME_LIMIT=540秒（9分钟），约推进 2-3 个实验的一段
- 大种群每轮约推进 1000-1500 tick
- 小种群每轮约推进 3000-5000 tick
- 实际总耗时约 12-15 小时（含间歇性崩溃重试开销）

## 五、结论

1. **云端 Python 路径速率**：大种群 12.5 tick/s，初始增长 27.6 tick/s
2. **单实验平均约 76 分钟**（大种群），小种群约 25 分钟
3. **Rust 路径（sim_core）预计提速 10-12 倍**（参考审计报告），大种群可达 125-150 tick/s，单实验约 6-8 分钟
4. 当前云端 2 核配置适合 Python 路径的分段续跑，不适合长时间高负载
