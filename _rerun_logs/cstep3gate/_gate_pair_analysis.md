## ⑥ 边界声明（**本批不判读**，R114a）

1. **12k 是短尺度**（C1a 用 60k）⇒「生态读数无差异」**可能只是时间不够**，**不得**读成「蹭归因无害」
2. `block_frac` = **到达中被拦的比例**，**不等于**「能量的 36% 被拦住」（能量口径见 `oracle.ledger`）
3. `oracle_ratio` 下降是**操作检查**（门按构造拦掉一部分到达 ⇒ `ratio` 必然下降）——它证明**门确实接在付款上**（构念被正确改动），**不是**科学发现（内评 §四.1）
4. 本批设计目的 = **出测度** + 为「只计真通信时是否仍有阳性」**留数据** ⇒ **判读归仪器线**
